# Практические работы по фронтенд и бэкенд разработке

Ниже приведено краткое описание выполненных практических работ на основе реализованных заданий в проекте.

## Практическая работа №7

### Что было сделано

- Реализован базовый backend для регистрации и авторизации пользователя на `Express`.
- Добавлено хеширование паролей с помощью `bcrypt`.
- Реализован вход пользователя с выдачей `JWT access token`.
- Добавлено логирование запросов на сервере.
- Пользователи хранятся во временном массиве в памяти приложения.

## Практическая работа №8

### Что было сделано

- Реализован backend для работы с товарами.
- Добавлен CRUD для сущности `goods`.
- Подключена Swagger-документация для API.
- Реализован endpoint `/api/auth/me` для получения данных авторизованного пользователя.
- Добавлена проверка `Bearer token` через middleware.
- Подготовлен frontend на `React + Vite` для работы с backend.

## Практическая работа №9

### Что было сделано

- Реализована система `access token + refresh token`.
- Добавлен endpoint `/api/auth/refresh`.
- Реализована ротация refresh-токенов.
- На клиенте добавлено автоматическое обновление access-токена при получении `401`.
- Сессия пользователя восстанавливается после перезагрузки страницы.

## Практическая работа №10

### Что было сделано

- Добавлены роли пользователей: `user`, `admin` и `seller`.
- Реализованы отдельные страницы регистрации и входа.
- Главная страница с товарами доступна только после авторизации.
- Для обычного пользователя на карточке товара доступна только кнопка `Buy`.
- Для продавца доступны действия `Add good`, `Edit` и `Delete`.
- Для администратора доступны действия `Add good`, `Edit`, `Delete`, а также панель управления пользователями.
- Добавлена защита backend-эндпоинтов по роли администратора и продавца.

## Практическая работа №11

### Что было сделано

- Реализована отдельная admin-страница управления пользователями.
- Добавлена таблица пользователей с отображением:
  - `id`
  - `username`
  - полного имени
  - email
  - роли
  - статуса блокировки
- Добавлены кнопки `Block / Unblock`.
- Добавлена рабочая смена роли пользователя `user/admin/seller`.
- При смене собственной роли интерфейс администратора или продавца обновляется автоматически.
